# G5 文案

目的：把设计卡变成三类文字：页面文字（卡片、标签、旁白）、逐字稿（`content/notes.py`）和下钻原文（`content/orig.py`）。

## 顺序

1. 逐页写页面文字。先写强调句和旁白，再写卡片。规则见 `reference/copy-rules.md`。
2. 写逐字稿，每页 1 段开场，再每步 1 段。规则和示例见 `reference/speaker-notes.md`。
3. 写 `orig.py`。每个有入排、窗口、阈值的页面列出相关条款，用 `P.line('行首几个字')` 取原文。
4. 对照 `plan/facts.md` 核数字：页面上的每个数字、日期、窗口都能在事实表里找到。

## 自查（逐页过）

- [ ] 强调句写的是一条规定，不是口号；
- [ ] 旁白每步一句，40–70 字，和画面同步；
- [ ] 卡片有标题，正文分条；
- [ ] 重点标记每卡不超过 2 处，每页不超过 4 处；
- [ ] 方案外内容已标 `[建议]` 或 `[操作建议]`，CRO 流程已标来源；
- [ ] 量表写了条目和分级，NCS 写了理由；
- [ ] 没有禁用词（G6 用 `check_project.py` 复查）；
- [ ] 逐字稿段数等于步数，开场不重复强调句原话。

## 关卡

`content/notes.py`、`content/orig.py` 写完。等 G6 构建之后，`check_project.py` 不报 ERROR。
