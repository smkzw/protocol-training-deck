# G4 逐页设计

目的：动手写代码之前，每页先写一张设计卡（`plan/design.md`，每页一节）。设计卡决定页面讲什么、每一步看到什么。写代码只是照着设计卡落实。

## 设计卡模板（每项都填）

```markdown
## incl_easi · V1 · 疾病严重程度与肝功能的入排要求
- 模式：P6 规则原文 + 图形测量 + 判定板（patterns.md）
- 强调句：EASI、IGA、BSA 在**筛选期和基线两次**都要达标；ALT/AST 超过 **3×ULN** 直接排除
- 听众要带走的一句话：筛选期达标不能替代基线
- 构图（画布 1168×524，单位为画布单位）：
  - 左栏 x0–540：原文卡 (0,0,540,176) → 判定板 (0,196,540,…)
  - 右栏 x600–1120：三根阈值条，每根 64 高
  - 旁白：(0,414,1168,106) 通栏
- 逐步故事线：
  | 步 | 画面变化 | 旁白（一句） | 颜色 |
  |---|---|---|---|
  | 1 | 原文卡出现，阈值加下划线 | 三条都写“筛选期和基线时” | 品牌橙 |
  | 2 | V1 三根阈值条出现；判定板三行 ✓ | V1 三项都达标 | 绿 |
  | 3 | 同一位受试者基线：EASI 条移到 15；判定板第一行 ✗；红色提示卡 | 基线必须再次达标 | 红 |
  | 4 | 换成排除 1 原文；ALT 条 3.4×ULN；琥珀提示：允许复查一次 | 复查仍超标即排除 | 琥珀 |
- 正例 / 反例：V1 全部达标 / 基线 EASI 15；ALT 超标后复查
- 原文：页面上用 Verbatim 引用入选 2–4、排除 1、4.1 复查；下钻用 Source 列 3.5.1、3.5.2、4.1
- 组件：quote_card、threshold_bar、verdict_board、alert、narr
- 风险点：旁白长度；第 3 步红卡不能盖住阈值条
```

## 设计规则

### 构图

- 可用区 1168 × 524（总画布 1168 × 564，顶部 40 是强调句）。页面元素 x 从 0 到 1168，y 从 0 到 524，y + h ≤ 524。
- 先决定“主体”放在哪里，主体是图形，约占画布 55–70%。再放辅助卡（规定、原文、清单），最后放旁白。
- 旁白（`p.narr`）只占一个槽位，三种常用槽位：
  - 通栏底部 `(0, 414, 1168, 106)`：适合背景页、规则页；
  - 右下 `(400, 424, 768, 100)`：适合左侧是清单的访视页；
  - 右下窄槽 `(580, 404, 588, 120)`：适合左侧是流程或卡片的页。
  三个槽位的 y + h 都等于 524；改动时保持 y + h ≤ 524。旁白卡会被构建自动收紧到内容高度，所以槽位宁大勿小。
- 左右两栏之间留 40–60 单位，卡片之间留 16–20，卡片离画布边缘 0。
- 一页最多 4 个视觉区块（主体、规定卡、示例卡、旁白）。超过就拆页。

### 逐步故事线

一页 3–6 步（最多 7 步），每步只引入一个新信息。常用节奏见 `reference/scene-storyline.md`：

- 规定 → 正例 → 反例 → 正确做法（4 步，最常用）；
- 背景 → 机制 → 药物作用 → 给药（3 步）；
- 流程骨架 → 例 A 走一遍 → 例 B → 反例 C（4 步）；
- 起算日 → 推算窗口 → 落到日历 → 越界情形 → 复查（5 步）。

每一步都要回答两个问题：画面上新出现或改变了什么？旁白用一句话说什么？只有文字变化、画面不动的一步，是坏的一步。

### 正反例

- 反例要真实，选容易漏、容易混、不好做到的情形，不选一眼就能看出的错误。
- 反例和正例放在同一个位置轮换：`s=k, o=k+1` 叠放，避免满屏卡片。
- 反例之后要给出方案规定的正确做法，或者说明后果，例如“该样本不符合方案要求，按偏离记录”。不要停在“错了”。
- 需要研究者判断的情形，不判对错，写“由研究者评估…”，用琥珀色。

### 原文

- 页面上引用方案原文时，先用 `q = Verbatim('src/protocol.md')` 校验**不带任何标记**的原文，再在返回值上加标记：
  `q('筛选期和基线时EASI评分≥16分。').replace('≥16分', '__≥16分__')`。
  不要把 `__…__` 写进 `q(...)` 的参数里，那样原文对不上，构建会失败。
- 下钻原文写在 `content/orig.py`，用 `Source` 按行首锚点取。凡是有入排、窗口、阈值的页面都要有下钻。

### 图

- 疾病、解剖、机制、器械类页面需要示意图。先用 `engine/svgart.py`（见 `reference/svg-fallback.md`）；用户提供了生图能力时，再按 `reference/image-generation.md` 生成。
- 图只做示意，不画写实人体，不画面部。

## 关卡

`plan/design.md` 覆盖 outline 的每一页，每张卡的逐步表行数等于计划的步数，然后进入 G5 和 G6。
