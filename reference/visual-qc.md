# 视觉 QC

视觉 QC 分两层：自动检查找出可以量化的问题，人工看截图找自动检查看不出的问题。两层都要做。例如，键帧没有复原、卡片稀疏、旁白卡过大、SVG 标签压线这几类问题，都只有看截图才能发现。

## 1. 自动检查（qa/deck-qa.js）

每页的每一步都会检查一遍。

| 代码 | 含义 | 常见原因 | 修法 |
|---|---|---|---|
| LAYOUT_OUTSIDE | 元素超出画布（可用区 1168 × 524（总画布 1168 × 564，顶部 40 是强调句）） | y + h > 524；x + w > 1168 | 改坐标；`visit_checklist` 的默认高度已按 524 − y 计算 |
| LAYOUT_OVERFLOW | 文字超出所在的框（卡片溢出） | 框高按短文本估算；节点太窄导致折行 | 加高、加宽，或删字；不要缩字号 |
| TEXT_COLLISION | 两个框的文字互相重叠（文字重叠） | 同一位置的两个元素同时在场；标签压到相邻元素 | 检查 `s`/`o` 是否成对；有意覆盖的卡片用 `alert`/`case_card`（自带 `cover`） |
| NARR_OVERFLOW | 旁白超出旁白卡 | 旁白太长或旁白卡太矮 | 删字（每步一句，≤70 字）或加高旁白卡 |
| TITLE_LOGO | 标题压到右上角 Logo | 标题和小字太长 | 缩短；构建时已有 WARN |
| IMG_BROKEN | 图片加载失败 | 路径错；资源没拷进 `content/assets` | 修路径 |
| NOTES_MISMATCH / NO_NOTES | 逐字稿段数不等于步数，或没有逐字稿 | 加减了步骤，逐字稿没同步 | 改 notes.py |
| ENTRY_FLASH | 进页时闪现后续步骤的内容 | 引擎被改动 | 不要改 `sop2.js` 的 enter 逻辑 |
| LOGO | 每页不是恰好一枚 Logo，或 Logo 加载失败、被拉伸变形 | 页面里另放了 Logo 图；改了 `kz-logo` 样式 | 删掉多余的 Logo；Logo 只由引擎放置 |
| FOOTER | 页脚不是恰好两槽，或页码不等于“第 n 页 / 总页数” | 往页脚加了内容；改了引擎 | 页脚只留部门日期和页码（康哲 CORE-04） |
| LEAD_OVERFLOW | 强调句被截断 | 强调句超过一行（构建时已报 ERROR） | 缩短强调句；不用省略号 |
| FONT_FLOOR | 可见文字小于 12 逻辑 px | 内联写了小字号；用了 `f10`/`f11` | 删字或重排，不缩字 |
| DRILL | “方案原文”下钻打不开、为空、关不上，或在弹层里按键会推进页面 | `orig.py` 锚点错；改了下钻或步骤引擎 | 修锚点；不改 `kz-drilldown.js` / `sop2.js` |
| PRESENTER_SYNC | 演讲者窗口（S）的逐步同步失效：hello 不回步号、step 不推进、末步后不翻页 | 改了 `sop2.js` 或 vendored `runtime.js` | 恢复引擎文件（`new_project.py --update-engine`） |

菱形节点（`.dia`）按内切正方形测量文字，报 LAYOUT_OVERFLOW 就是字真的多了：缩短文字或加大菱形。没有“已知可接受”的报错项，`summary` 必须为空。

运行方法见 `qa/README.md`。`--shots 2` 时会给每页每一步各存一张图（`qa/shots/NN-k.png`）。交付前再跑一次 `python3 -I scripts/qa.py --all-viewports --shots 0`：在康哲验收的五档视口（1920×1080、1280×720、1536×730、1920×940、2560×1080）各检查一遍版面，问题会标出视口。

## 2. 人工截图检查清单（逐页看最终态；关键页逐步看）

### 2.1 动画与步骤
- [ ] 第 0 步（刚进页）只有标题区、强调句，以及作为本页“地图”的静态骨架（未勾选的清单、空的时间轴）；不出现答案、示例或判定。
- [ ] 每一步都有可见的画面变化，与旁白对应，没有“只换旁白”的步。
- [ ] 替换类元素（`s=k, o=k+1`）在交接那一步不同时出现、不留空档。
- [ ] **键帧复原**：反例中被移动、变色、改文字的元素，在后面的步骤里回到正确状态。键帧会一直保持，不会自动复原，每个属性（x、y、w、h、c、t）都要显式写回。
- [ ] 最后一步的画面是“正确的样子”，因为打印和预览显示的是最后一步。
- [ ] token 停在节点入口（箭头处），不压住节点文字；平行的 token 互相错开。
- [ ] 连线在 token 走之前已经画出，或者两者同一步出现。
- [ ] 回退（←）到上一步时，画面与第一次前进时一致。

### 2.2 重叠
- [ ] 文字与文字：标签、tag 不压住相邻卡片的文字。
- [ ] 元素与元素：卡片之间间距 ≥16；反例卡有意覆盖时，背景不透明（cover）。
- [ ] 连线与文字：SVG 标签不压在箭头或连线上（参考：MoA 示意图的标签曾压线，后改坐标）。
- [ ] 不透明面板压住了面板内的连线时，面板改为虚线描边 + 半透明底。
- [ ] 计时环、计数等叠在一起的元素，数字居中，不压到圆环。

### 2.3 溢出
- [ ] 文字溢出：卡片底部没有被裁掉的行；tag 不超出所在格子（参考：“2 周”tag 曾溢出卡片）。
- [ ] 卡片溢出：卡片不超出画布底边（y + h ≤ 524），不压到页脚。
- [ ] 节点内标题不折成两行（或者折行是有意的）。
- [ ] 强调句没有被省略号截断。

### 2.4 疏密
- [ ] 卡片里的文字不全挤在上方、下方大片留白。卡片过高时，降高度、加图，或用 `stretch`。
- [ ] 页面下方没有大片空白。
- [ ] 旁白卡高度与内容匹配。构建提示 `autofit skipped` 时一定要看这一页。
- [ ] 内容居中的卡片（提示卡）高度不超过内容高度的 2 倍。
- [ ] 一页不超过 4 个视觉区块。

### 2.5 文字与标记
- [ ] 最小字号 12；同一角色字号一致。
- [ ] 重点标记每卡 ≤2 处、每页 ≤4 处。
- [ ] 没有字面上的 `<br>`、`**`、`__` 等未渲染标记。`md()` 会转义 HTML，要换行就在文本里写 `\n`。
- [ ] `[建议]`/`[操作建议]` 显示为灰色小字“（建议）”，没有显示成方括号原文。
- [ ] 下钻按钮“方案原文”出现在有入排、窗口或阈值的页面上，弹层内容正确，按 Esc 能关闭。

### 2.6 品牌与框架
- [ ] 标题区：阶段标签 + 标题 + 小字在一行内，不压 Logo；左上角双菱形标记正常。
- [ ] 页脚：左侧“部门｜年月”、右侧页码，只有这两项（康哲 CORE-04；步数在演讲者窗口里看）。
- [ ] 没有通长装饰色条；背景是浅色。
- [ ] 封面、目录、章节页的文字没有被版式截断。

### 2.7 视口
- [ ] 1920×1080 为主。另外抽查 1280×720 和 2560×1440，看等比缩放是否正常。
- [ ] 4:3 视口（1024×768）右侧会被裁切，这是 16:9 框架的已知限制。放映前把投影设置为 16:9。

## 3. 交互检查（每次交付前做一次）

- 不自动播放：打开后静置 3 秒，画面不动。
- →、↓、空格、PageDown 前进；←、↑、PageUp 后退；每一页的最后一步之后，再按一次才翻页；倒退进入上一页时停在它的最后一步。
- 触控板一次滑动走一步；手机或平板滑动可以翻步。
- S 打开演讲者窗口，逐字稿高亮随步骤移动；O 总览；F 全屏；`#/n` 直达第 n 页。
- 悬停左侧“目录”标签展开目录，点页码可跳转；在章节之间移动鼠标时，列表不闪动。
- 打印（Ctrl/Cmd + P）每页一张，显示最终态。
