# 字体、字号与间距

画布是 1168 × 564 个逻辑单位（顶部 40 为强调句，页面元素可用区 1168 × 524），按视口等比缩放（`--kz-u`）。字号类 `f12`–`f56` 也跟着缩放，所以写代码时只用类名，不写 px。

## 1. 字号角色（同一页内，同一角色的字号必须相同）

| 角色 | 字号 | 粗细 | 位置 / 类 | 说明 |
|---|---|---|---|---|
| 页面标题 | 32 | 700 | 标题区（引擎生成，康哲 `--kz-type-page-title`） | 写内容名称，例如“V4 · W4 · 第 2 次给药” |
| 标题小字 | 16 | 400 | 标题区 `small` | 时间、窗口、条款号 |
| 阶段标签 | 14 | 700 | 标题区左侧 chip | 来自 CHAPTERS 第 4 项，≤6 字 |
| 强调句 | 18 | 700 | 画布顶部一行 | 只能一行，构建时会检查 |
| 卡标题 | 16 | 700 | `pn-t`（`p.panel` 的 title） | |
| 区块小标题 | 15 | 700 | `f15 b ink` | 右栏分区标题，可带图标 |
| 正文 | 14 | 400 | 默认 | 节点标题、旁白 |
| 次要正文 | 13 | 400 | `f13` | 卡内条目、清单项、原文卡 |
| 注释 / 标签 | 12 | 400 或 700 | `f12`、`tag` | 下限，不能再小 |
| 大数字 | 20–28 | 700 | `f20`/`f24`/`f28` + `num` | 计时、计数、关键值 |
| 封面级 | 32–56 | 700 | `f32`/`f40`/`f56` | 只在极少数强调场合用 |

- 最小 12px。放不下时先删字、重排或拆页，不要缩字号，也不要用 `font-size:11px` 内联。
- 数字、日期、编号加 `num`（Arial、等宽数字），保证对齐。
- 正文字体沿用 html-ppt 的系统字体栈 `--font-sans`（Inter、Noto Sans SC、系统 UI 字体、Arial）；SVG 内文字、导航和封面用康哲字体栈 `var(--kz-font)`。只用本机已装字体，不引入网络字体，保证离线可用。实际效果：macOS 上中文是苹方，英文数字是 SF；Windows 上中文是微软雅黑，英文数字是 Segoe UI / Arial。不要给 `.kz` 加 `font-family`（用户认可的豁免，见 `brand-compliance.md` §3）。
- 页脚 18（康哲 `--kz-type-footer`，引擎固定）。正文、卡标题和下限采用培训场景字号（14 / 16 / 12），比康哲规定（20 / 24 / 16）小，是用户认可的豁免，见 `brand-compliance.md`。

## 2. 行高

| 场景 | 行高 |
|---|---|
| 默认正文 | 1.4（画布默认） |
| 原文卡 | 1.55（`quote_card` 已设） |
| 旁白 | 1.45 |
| 节点、清单 | 1.3–1.35 |
| 多行大字 | `lh12` |
| 宽松段落 | `lh15` |

## 3. 间距（单位都是画布单位）

| 项 | 值 |
|---|---|
| 卡片内边距 | 上下 12、左右 14（`pn` 已设） |
| 卡标题与正文 | 6 |
| 卡与卡 | 16–20 |
| 左右两栏之间 | 40–60 |
| 清单项之间 | 4（`ck` 已设）；组标题上 6、下 2 |
| 节点内边距 | 7 / 10 |
| 旁白卡与上方内容 | ≥ 12 |
| 元素离画布边缘 | 0（画布本身已经离开屏幕边缘） |

## 4. 容量估算（写之前先算，省得截图后返工）

- 一个汉字的宽度 ≈ 字号；英文和数字 ≈ 0.55 × 字号。
- 一行能放的汉字数 ≈ (框宽 − 左右内边距 28) / 字号。例如宽 540 的卡，f13 一行约 39 字。
- 一张卡能放的行数 ≈ (框高 − 上下内边距 24 − 标题 28) / (字号 × 行高)。例如高 176 的原文卡，f13 × 1.55 约 6 行。
- 节点宽 150 时放 f14 标题，最多约 8 个汉字；超过会折行，要加宽节点或缩短文字。
- 强调句：宽 1168 − 130 ≈ 1038，f18 约 57 个汉字，含按钮位置时按 50 字算。
- 标题区：阶段标签 + 标题（32）+ 小字（16）的总宽不超过 925，构建时会检查。

## 5. 文字排布

- 每张文字卡都有卡标题，正文分条，每条一句。
- 卡片里的文字不要只挤在上方。卡片过高时，要么降低卡片高度，要么加图形，要么用 `pn stretch` 让条目均匀分布。
- 避免孤字行（一行只剩 1–2 个字）：改写句子或调整宽度。
- 不用省略号截断任何文字（康哲 TYPE-03）。强调句超过一行时构建报 ERROR，QA 报 LEAD_OVERFLOW。
- 段落已默认 `text-wrap: pretty`、标题 `balance`（康哲 TYPE-04），这只能减少孤字行，仍要看截图。
