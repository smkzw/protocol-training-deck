# 配色与视觉差异

风格：浅色暖白底、玻璃质感卡片、康哲橙作品牌色。颜色按语义使用，不做装饰。

## 1. 色板（已写在 `engine/static/kz/kz-tokens.css` 和 `components.py`，直接用类名或常量）

| 语义 | 色值 | Python 常量 | CSS 类 | 用在 |
|---|---|---|---|---|
| 品牌 / 当前焦点 | #FF9900 | `BRAND` | `tag brand`、`w brand`、`nd on`、`t-brand` | 强调句关键词、当前讲解对象、给药时刻、主路径 |
| 正确 / 符合 | #2F8A57 | `OK` | `tag ok`、`nd ok`、`bar ok`、`t-ok` | 正例、达标、窗口内、已完成 |
| 错误 / 不符合 | #C00000 | `BAD` | `tag bad`、`nd bad`、`hl-ring bad`、`!!文字!!` | 反例、超标、越界、偏离 |
| 需判断 / 提醒 | #D98E00 | `WARN` | `tag warn`、`nd warn`、`t-warn` | 需研究者评估、允许复查、容易混淆 |
| CRA / 系统 | #4A6D8C | `CRA` | `tag cra`、`bar cra`、`rc-cra` | CRA 角色、PK/样本条、系统界面 |
| MM | #E98A00 | `MM` | `tag mm`、`rc-mm` | 医学经理角色 |
| PV | #A85F34 | — | `tag pv`、`rc-pv` | 药物警戒角色 |
| 中性 | #9A948A | `GREY` | `tag`、`bar grey`、`mut` | 背景信息、非当前步骤 |
| 正文 | #3D4046 | — | `ink`（标题）、默认正文 | 文字 |

浅底色（卡片、高亮背景）只用半透明形式：`rgba(255,153,0,.07~.18)`、`rgba(47,138,87,.10~.55)`、`rgba(192,0,0,.08~.2)`、`rgba(217,142,0,.12~.45)`。

## 2. 搭配规则

1. 一页的主色只有一个，就是品牌橙。绿和红成对出现，表示正例与反例，不单独用作装饰。
2. 一页最多同时出现 3 种语义色（不算中性和正文）。角色色只在有角色头像或泳道时使用。
3. 同一个元素的颜色只表达一件事。例如 PK 条用 CRA 蓝，出错时加 `err` 变红，而不是一开始就画成红色。
4. 卡片用三种质感区分层级：
   - `pn`（玻璃，默认）：主内容卡；
   - `pn flat`（实白）：数据卡、清单、规格；
   - `pn tint`（浅橙）：方案原文、关键提示。
   一页最多 1–2 张 tint。
5. 提示卡 `alert` 的 tone 色只出现在标题图标和文字上，不做边条。
6. **禁止通长装饰色条**：卡片左边或顶边的整条彩色 border、整列色块都不允许。需要分组时，用卡标题、图标、留白或细分隔线。
7. 背景图只用 `body-quiet.webp`（正文页）和 hero 图（封面、目录、章节页），不加其他背景纹理。
8. 示意图：填充用暖中性 `#F3EDE3`，描边用 `#B9AE9C`，教学对象用品牌橙，禁区用红，允许用绿（见 `svg-fallback.md`）。

## 3. 每页的差异化（避免“套模板”）

用户最强烈的一次反馈是“几乎所有页面的设计都一模一样，全是简单的文字卡片”。下面 6 个维度中，相邻两页至少要有 3 个不同：

| 维度 | 可选值 |
|---|---|
| 主体图形 | 时间轴 / 日历 / 流程图 / 泳道 / 矩阵 / 阈值条 / 示意图 / 表单 / 计算器 / 漏斗 / 分类容器 |
| 构图 | 左右 4:6 / 左右 6:4 / 上下分区 / 全幅主体 + 底部旁白 / 三栏 / 中心放射 |
| 运动 | 擦除展开 / token 沿路径移动 / keyframe 位移 / 逐格出现 / 数字滚动 / 卡片轮换 / 打勾 |
| 旁白位置 | 通栏底部 / 右下 / 左下 |
| 示例形式 | 同位轮换 / 同人两时点 / 清单先错后对 / 元素位移 / token 分路 / 错列纠正 / 圈出 |
| 强调方式 | 下划线阈值 / 红圈 / 印章 ✓✗ / 高亮 / 计数环 |

做法：在 `plan/outline.md` 的每一行后面记下这 6 个维度的取值，相邻行逐一比较。

## 4. 质感细节

- 卡片圆角 16、节点圆角 12、tag 圆角 7，引擎已设好，不要内联改写。
- 阴影只用引擎自带的暖色阴影，不要加黑色硬阴影。
- 线条：中性连线 1.6，强调线加 `thick`（2.6），虚线 `dash` 表示可选或退回路径。
- 变暗用 `filter:opacity(.45)` 或 `is-dim`，不用内联 `opacity`。内联 opacity 会覆盖引擎的出场状态。
