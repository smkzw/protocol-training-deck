# Scene 故事线

一页就是一个 scene，按键一次推进一步。故事线分三层：全稿、章、页。每一层都要回答：听众此刻知道了什么，下一步要知道什么。

## 1. 全稿故事线

```
封面 → 目录 → [01 认识这个研究] → [02–05 跟着一位虚构受试者走完全程] → [06 例外情况怎么按方案处理]
```

- 第 1 章回答“这个研究是什么”：疾病是什么 → 药物作用在哪 → 研究怎么设计 → 终点用什么量表评 → 全程怎么安排 → 每次访视做什么。
- 第 2–5 章按受试者时间顺序推进。全稿用同一组虚构受试者编号（S01003 正例、S01007 复杂情形、S01008 资料示例），D1 固定为一个虚构日期，所有日期都从 `StudyDates` 算出。D1 只定义一次（`content/meta.py` 的 `DAY`），页面模块里写 `from meta import DAY`，然后用 `DAY(29)`、`DAY.window(29, 3)`、`DAY.date(-7)`。听众能感到这是同一个人一路走下来。
- 第 6 章按事件组织，每页是一个“遇到这种情况，方案怎么规定”。
- 章节页只放编号和标题；它的逐字稿说清本章讲什么、为什么排在这里。

## 2. 章内故事线

- 每章的第一页给出本章的“地图”（时间轴、流程或清单），后面的页逐个放大地图上的点。
- 章内页序按时间或判断顺序排：先要求（规定页），再计算或示例（示例页），最后审核或交接。
- 章末一页收束：审核、交接，或进入下一阶段的条件。

## 3. 页内故事线

### 3.1 一步只引入一个新信息

每一步都要同时回答：
1. 画面上新出现、移动或变色的是什么？
2. 旁白的那一句说什么？
3. 这一步的颜色语义是什么（中性、品牌、正、反、需判断）？

如果某一步只有文字变化、画面不动，就把它并进前一步，或者给它加一个画面变化（圈出、移动、变色）。

### 3.2 五种常用节奏

| 名称 | 步骤 | 适用 |
|---|---|---|
| A 规定-正-反-纠 | ① 规定/原文 ② 正例 ✓ ③ 反例 ✗ ④ 正确做法或后果 | 入排、窗口、时间点，最常用 |
| B 递进揭示 | ① 背景 ② 机制 ③ 药物作用 ④ 给药 | 背景、药物、终点 |
| C 流程走查 | ① 流程骨架 ② 例 A 走一遍 ③ 例 B 走另一支 ④ 反例 C | 判定流程、审核、揭盲 |
| D 时间推演 | ① 起算日 ② 推出区间 ③ 落到日历 ④ 越界情形 ⑤ 补救或复查 | 筛选期、洗脱期、超窗 |
| E 清单联动 | ① 窗口 ② 项目打勾 ③ 陷阱 fail ④ 改为 done ⑤ 给药/下次访视 | 访视页 |

### 3.3 正反例的多步展示模式

| 模式 | 做法 | 代码 | 适用 |
|---|---|---|---|
| **同位轮换** | 正例卡和反例卡放在同一位置，轮流出现 | 卡 A `s=2,o=3`；卡 B `s=3,o=4`；卡 C `s=4` | 版面紧凑；案例 ≥3 个 |
| **同人两时点** | 同一受试者在不同时间点测得不同值，判定板上该行由 ✓ 变 ✗ | 阈值条 `s=2,o=3` 与 `s=3`；`verdict_board` 帧 `{2: ('22 分 ✓','ok'), 3: ('15 分 ✗','bad')}` | 筛选和基线两次判定 |
| **清单先错后对** | 清单某项先变红叉，下一步变绿勾；旁边红卡换绿卡 | `visit_checklist` 帧 `{3:'fail',4:'done'}` | 访视操作陷阱 |
| **元素位移** | 时间轴上的竖线、窗口、条块随反例移动，最后一步移回 | `k={3:{'x':…}, 4:{'x':原值}}` | 时间安排、窗口 |
| **token 分路** | 多个案例 token 在同一流程里走不同分支 | `token({2:'a'})`、`token({3:'b'})` | 判定流程 |
| **错列纠正** | chip 先落进错误的分类，下一步移到正确分类 | chip `k={3:{'x':错列,'c':'err'},4:{'x':对列,'c':''}}` | 合并用药、分类 |
| **圈出** | 不改变画面，只用红圈圈出出错处 | `p.ring(x,y,w,h,'bad',s=3,o=4)` | 表单、日历中的单点错误 |

规则：
- 反例之后的那一步，必须回到正确状态，或者讲清后果。页面最后一步的画面是“正确的样子”，因为打印和预览都显示最后一步。
- 正例绿、反例红、需判断琥珀。同一页最多 3 个反例。
- 反例要真实：选容易漏的、容易混淆的、时间上卡边的、两条规则叠加的情形。不选一眼可见的错误。
- 需要研究者判断的情形，不判对错，写“由研究者评估……”，并说明方案依据。

### 3.4 步数

- 每页 3–6 步，最多 7 步。少于 3 步说明内容不够，可以并入相邻页；超过 7 步就拆页。
- 背景页 3–4 步，访视页 5 步，流程页 4 步。
- 进入页面时（第 0 步）显示标题区、强调句，最多再加一个静态骨架（未勾选的访视清单、空的要点清单）。答案、示例、判定一律从第 1 步起出现。开场逐字稿对应第 0 步。
