# 放映运行时

`deck/index.html` 不依赖网络，双击就能用 file:// 打开。运行时由三层组成：
- html-ppt runtime（MIT，`vendor/html-ppt/assets/runtime.js`，含演讲者窗口逐步同步补丁）：翻页、演讲者窗口、总览；
- 康哲品牌层（`kz/`）：等比缩放、下钻弹层；
- 步骤引擎（`sop2.js`）：负责逐步推进。

## 按键

| 操作 | 效果 |
|---|---|
| → ↓ 空格 PageDown Enter | 下一步；本页最后一步之后再按一次，翻到下一页 |
| ← ↑ PageUp Backspace | 上一步；在第 0 步时翻回上一页，并停在上一页的最后一步 |
| 触控板滑动 / 鼠标滚轮 | 一次手势走一步 |
| 触屏左滑、上滑 / 右滑、下滑 | 下一步 / 上一步 |
| S | 演讲者窗口（当前页预览、下一页预览、逐字稿、计时器；逐字稿高亮随步骤移动）。窗口里：← → ↑ ↓ 空格 PageDown、Prev/Next 按钮逐步推进主窗口；Home/End 首末页；R 计时清零；Esc 关闭窗口。主窗口关闭或无响应时，演讲者窗口 0.4 秒后自己翻页 |
| N | 底部备注抽屉 |
| O | 全部页面总览（缩略图显示每页最终状态；点缩略图跳页；Esc 关闭） |
| F | 全屏 |
| Home / End | 第一页 / 最后一页 |
| `#/n` | 地址栏直达第 n 页 |
| T / A | 不起作用：html-ppt 的主题切换、整页动画重放与本技能的品牌样式和步骤引擎冲突，已屏蔽 |
| 左缘“目录”标签 | 悬停或点击展开章节和页面目录，点页码跳转；Esc 关闭 |
| “方案原文”按钮 | 打开下钻弹层；Esc 或点空白处关闭；弹层内的按键和滚轮不会翻页 |

## 行为约定（引擎保证，不要改）

- 不自动播放，每一步都要按键触发。
- 一页的状态只由步号决定：`data-s`、`data-o`、`data-k` 按步号计算，所以后退是精确的。
- 进页时先关闭过渡，再切到入口状态（前进进入为第 0 步，后退进入为最后一步），所以不会闪现上一状态。
- 打印、`?preview`（演讲者窗口中的预览帧）、总览缩略图和系统“减少动态效果”都显示最终状态。
- 演讲者窗口与主窗口通过同名 BroadcastChannel 通信（`{type:'hello'|'step'|'stepstate'|'go'}`），QA 的 PRESENTER_SYNC 检查这一约定。
- 打印：`@page` 16 × 9 英寸，每页一张。
- 缩放：所有尺寸乘以 `--kz-un = 视口高 / 720`。总画布 1168 × 564（顶部 40 为强调句，页面可用区 1168 × 524）居中，宽屏时左右留白。

## 文件

| 文件 | 来源 | 可否改 |
|---|---|---|
| `vendor/html-ppt/assets/{base.css, runtime.js}` | html-ppt-skill（MIT）。base.css 与上游逐字节相同；runtime.js 只有一处补丁：演讲者窗口逐步同步与无响应时自行翻页 | 不改；`check_project.py` 核对两者的 sha256，维护技能改了它们时同步更新那里的哈希 |
| `kz/*` | 康哲设计系统运行层：tokens、缩放 bridge、下钻、观众端 | 不改 |
| `sop2.css`、`sop2.js` | 本技能的步骤引擎与样式 | 只有维护技能时才改，改完重跑全部 QA |
| `assets/` | Logo、正文背景、hero 图 | 换品牌时替换（见 README） |
